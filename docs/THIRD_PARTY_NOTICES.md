# Third-party implementation notes

Katcha's ChatGPT Codex subscription integration was implemented for interoperability
with OpenAI Codex and informed by the open-source Roo Code implementation.

- OpenAI Codex: https://github.com/openai/codex
- Roo Code: https://github.com/RooCodeInc/Roo-Code
- Roo Code license: Apache License 2.0

The Katcha implementation is written in Python for Katcha's own runtime and uses its
own product identity (`originator: katcha`). Roo Code trademarks, branding, and
application identity are not reused.
